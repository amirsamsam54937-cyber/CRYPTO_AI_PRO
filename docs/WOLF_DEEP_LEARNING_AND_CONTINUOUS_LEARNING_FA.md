# یادگیری عمیق و چرخه تقویت AMIRARSALAN TRADER WOLF

## معماری شبکه عصبی

مدل اختیاری برنامه یک ensemble شامل ۱۰ شبکه عصبی عمیق MLP است. هر عضو معماری چندلایه ۷→۶۴→۳۲→۱۶→۱ دارد و با تابع فعال‌سازی tanh، منظم‌سازی L2 و توقف زودهنگام آموزش داده می‌شود. ورودی‌ها ویژگی‌های نرمال‌شده روند، RSI، قدرت روند، حجم نسبی، الگوی کندل، نوسان و امتیاز فنی هستند. خروجی، امتیاز جهت‌دار کمکی است؛ احتمال سود یا تضمین موفقیت معامله نیست.

## چرخه یادگیری مداوم

1. برنامه نتیجه سیگنال‌های قبلی را از روی کندل‌های عمومی بعدی مشاهده می‌کند و در دفترچه محلی ثبت می‌کند.
2. یادگیرنده آنلاین داخل دستگاه به‌صورت محدود و محافظه‌کارانه از این بازخوردها به‌روزرسانی می‌شود؛ داده خام و دفترچه روی دستگاه باقی می‌ماند.
3. GitHub Actions هر روز ساعت 04:17 UTC و همچنین با اجرای دستی، تلاش می‌کند مدل عمیق را با تاریخچه تازه بازار آموزش دهد.
4. داده فقط از API عمومی canonical بایننس USD-M دریافت می‌شود. HTTP 451 به‌عنوان منع دسترسی پذیرفته می‌شود؛ هیچ دامنه جایگزین، پراکسی، mirror یا داده ساختگی استفاده نمی‌شود.
5. مدل جدید فقط پس از ارزیابی زمانیِ purged holdout، وجود ۱۰ عضو، حداقل ۳۰۰ نمونه آزمون، balanced accuracy بالاتر از 0.51 و log-loss بهتر از baseline فراوانی کلاس پذیرفته می‌شود.
6. وزن‌های پذیرفته‌شده به مخزن commit می‌شوند و build اندروید که به تغییرات asset حساس است، APK تازه می‌سازد. اگر داده یا معیارها کافی نباشند، مدل جدید منتشر نمی‌شود و وزن‌های قبلی حفظ می‌شوند.

## محدودیت‌های مهم

- «همیشه در حال یادگیری» به معنی یادگیری محلی هنگام دریافت بازخورد و تلاش زمان‌بندی‌شده روزانه برای بازآموزی عمیق است؛ گوشی خاموش، برنامه force-stop شده، اینترنت قطع یا محدودیت Android/شبکه می‌تواند یادگیری زنده را متوقف کند.
- اگر API بایننس از منطقه اجرا HTTP 451 بدهد، آموزش عمیق جدید انجام نمی‌شود. در این وضعیت برنامه از قواعد فنی و یادگیرنده محلی موجود استفاده می‌کند و نباید وانمود کند وزن‌های جدید آموزش دیده‌اند.
- سیگنال‌ها و برچسب‌های ژورنال تقریبی‌اند؛ قیمت کندل جایگزین fill واقعی، کارمزد، لغزش، funding و کیفیت اجرای سفارش نیست.
- این چرخه صرفاً تحلیل و سیگنال است و هیچ اتصال حساب، کلید API یا اجرای معامله‌ای اضافه نمی‌کند.
